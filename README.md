## 📌 Featured Projects

### 🏆 [SportsManager](https://github.com/furkannpala/SportsManager)
Java desktop application for managing sports teams and club operations. Built as a Maven project with a layered `com.sportsmanager` package structure and a dedicated unit test suite. My longest-running original project — 85+ commits.

![Java](https://img.shields.io/badge/Java-F97316?style=flat-square&logo=openjdk&logoColor=white)
![Maven](https://img.shields.io/badge/Maven-F97316?style=flat-square&logo=apachemaven&logoColor=white)
![JUnit](https://img.shields.io/badge/JUnit-F97316?style=flat-square&logo=junit5&logoColor=white)

### 🎥 [Real-time Face Blurring](https://github.com/furkannpala/Real-time-Face-Blurring)
Detects faces in a live webcam stream and blurs them on the fly. Uses OpenCV's Haar cascade classifier, so it stays fast enough for real-time processing on ordinary hardware without a GPU.

![Python](https://img.shields.io/badge/Python-F97316?style=flat-square&logo=python&logoColor=white)
![OpenCV](https://img.shields.io/badge/OpenCV-F97316?style=flat-square&logo=opencv&logoColor=white)
![Haar Cascade](https://img.shields.io/badge/Haar_Cascade-F97316?style=flat-square)

### 📄 [free-cv-maker](https://github.com/furkannpala/free-cv-maker)
Privacy-first CV and cover-letter builder that runs entirely in the browser — no account, no server. 7 templates, drag-and-drop sections and PDF export.

![TypeScript](https://img.shields.io/badge/TypeScript-F97316?style=flat-square&logo=typescript&logoColor=white)
![React](https://img.shields.io/badge/React-F97316?style=flat-square&logo=react&logoColor=white)
